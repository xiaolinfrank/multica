# 个人保存视图与驾驶舱汇报模式

本合同记录当前实现的客户端能力。它延续 [UI/UX 设计第 7、9 节](ui-ux-design.md)，不增加服务端视图、共享权限或报告发布模型。视觉范围限驾驶舱。

## 个人保存视图

保存视图是**本设备、当前账号、当前工作区**的个人偏好。浏览器配置文件与桌面应用的本地存储彼此独立，不共享、不跨设备同步，也不生成可供团队复用的视图链接。

### 支持的内容

| 工作面 | 保存内容 |
| --- | --- |
| 工作总览 | 项目/模块范围、我的/团队、事项类型、摘要或完整待处理视图 |
| 执行计划 | 项目/模块范围、甘特/表格/责任/里程碑/预算付款/经营概览子视图、搜索、根分支过滤、月/周缩放、财务显示开关、时间轴工具栏开关 |
| 会议中心 | 项目/模块范围、列表/月/周/议程/时间线、搜索、日期窗、日历锚点、工作线/类型/状态/参与方过滤、已有“仅显示”条件 |
| 治理中的变更 | 项目/模块范围、搜索、待确认/已决定/全部、计划字段检查的展开状态 |

只保存已经存在且可应用的设置。当前没有独立的排序、列配置或行密度控制，因此定义中不加入这些空字段。未实现的产出物、验收、风险、自动化等能力不会作为保存视图的支持项。

以下内容不保存：

- 选中的执行任务、会议、行动或产出物对象，相关对象的临时检索范围；
- 分页游标、页码、滚动位置、选中的日历日期、树节点展开状态；
- 服务器对象、结果列表、计数、目录名称缓存、成员信息、权限、版本指针；
- 业务草稿、正在执行的命令或智能体运行状态。

打开对象详情或按某个执行任务查看相关会议时，仍可管理已有个人视图；保存当前设置需回到支持的主工作面。日期窗保留显式日期；未指定日历锚点时，工作面的默认日期继续按原规则计算。

### 保存、恢复和错误

入口支持保存当前设置、按名称查找、应用、重命名、用当前设置覆盖和删除。覆盖与删除明确指出目标视图。每个账号/工作区最多保存 30 个视图，名称最多 80 个字符，同一集合内不允许仅大小写不同的重名。

记录通过 `StorageAdapter` 存储，键包含账号 ID 与工作区 UUID。定义经版本化 zod 白名单解析；写入设备存储成功后才更新可见列表。存储失败时保留命名输入，不显示保存成功。损坏或不支持的记录显示读取错误，不当作可覆盖的空集合。

多个桌面标签页的账号/工作区命名空间可同时存在，互不切换对方的当前集合。退出账号清空内存及旧会话指针；本设备记录按原账号隔离保留。写入前检查对应集合已成功加载，写入后的会话代数检查防止清理操作之后恢复旧内存。

应用视图只恢复白名单中的客户端设置，并从第一页开始。服务器事实仍属于 TanStack Query。所保存的项目/模块 UUID 交由现有真实范围读取验证；已删除或失去权限的范围不会被按名称猜配，也不会悄悄改成全部项目。用户可通过现有范围控件选择有效范围，再覆盖或删除旧视图。

个人视图与返回位置是两件事：应用个人视图从第一页开始，不恢复“保存时的滚动位置”；进入对象后返回仍使用已有会话内筛选、分页和滚动上下文。

## 汇报模式

通过当前驾驶舱 URL 进入 `report=1`。返回工作视图时只移除汇报标记，保留原项目/模块、子视图、对象深链和日期参数；已有会话存储负责恢复工作面的筛选和滚动位置。

### 数据与口径

汇报只读取现有工作总览安全读模型，并经过额外的显式字段白名单投影。它不请求包含预算、供应商等字段的完整计划读模型，也不将任务正文或业务写入能力传给汇报组件。

当前包含：

- 驾驶舱标题和**工作区目标**、目标日期；目标来自全工作区 Cockpit，不冒充所选项目的独立目标；
- 所选范围内的执行任务数量、主归属任务的未结束/完成/关闭/未知状态计数；
- 逾期、受阻、未分派等真实异常计数；
- 执行任务、团队待处理和近期会议的有界预览，以及实际来源入口。

任务完成数不是 L3 验收通过数。未实现的正式成果/验收事实不参与汇报，也不由任务状态或运行结果推断。预览沿用总览返回的实际条数与总量，通常为待处理 8 项、执行任务 6 项、近期会议 6 项；完整集合仍在工作视图中按服务端分页查看。

页面明确展示：

1. 项目/模块范围；
2. 计划判断日期；
3. 服务器返回的数据读取时间；
4. 会议预览的真实时间窗；
5. 所含数据类别与未包含的预算、供应商、任务正文。

计划判断日期用于当前事实的逾期判断，**不是历史状态快照**。汇报读取结果也不是已经发布的报告或项目基线。

### 展示与返回

汇报为只读展示，不提供评审、批准、分派、重试业务任务等操作。来源链接在新标签打开真实对象；改变业务仍在对应工作台完成。

进入汇报时固定本会话的计划判断日期，跨午夜不会自动改变；同一会话手动刷新仍用该判断日期读取当前事实，退出再进入才采用新的当前日期。

数据由用户显式刷新。焦点切换、重连和普通缓存失效不会自动替换正在展示的内容。刷新失败时保留原结果及原读取时间，明确标记失败并允许重试，不伪造零值。

当前应用接线**没有提供打印或 PDF 能力**，因此不显示这些操作。组件仅预留可注入的真实打印能力；将来实际接入与验收后再开放，不把入口存在当作已完成导出。

## 实现与验证位置

- 定义捕获与应用：`packages/core/cockpit/saved-views.ts`。
- 设备存储和命名空间：`packages/core/cockpit/saved-view-store.ts`。
- 汇报白名单与读取：`packages/core/cockpit/report-model.ts`、`report-queries.ts`。
- 界面：`packages/views/cockpit/components/cockpit-saved-views.tsx`、`cockpit-report.tsx`。
- 各实现旁的测试覆盖字段排除、首屏恢复、账号/工作区隔离、写入失败、集合上限、汇报字段白名单、手动刷新、原路径返回和能力门禁。

测试状态与真实浏览器证据以本阶段实施记录为准；本合同不把组件回归或本机静态检查写成 agent 3 浏览器验收。
